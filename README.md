# ระบบประเมินบุคลากร ฉบับนักเรียน Vue + Vuetify แยก API

ฉบับใหม่สำหรับฝึกระดับพื้นฐาน ใช้ Vue Options API (`data`, `methods`) และ Express/MySQL ไม่มี Router, Pinia หรือระบบสำรองข้อมูล

- `frontend/` — หน้า `.vue`, Vuetify, Vite พอร์ต **5175**
- `backend/` — API และ MySQL พอร์ต **3301**
- `manual/index.html` — เริ่มคู่มือ 6 ระบบ พร้อมโค้ดและจุดหยุดตรวจแต่ละบท
- `manual/code/step-1` ถึง `step-6` — ไฟล์ที่ต้องเพิ่ม/แทนในบทนั้น ต้องทำต่อจากบทก่อนหน้า

## เปิดเฉลยที่ทำครบแล้ว

ติดตั้ง Node.js **22.12 ขึ้นไป** และ MySQL 8 ก่อน เปิด Terminal ในโฟลเดอร์นี้

```powershell
npm.cmd run install:all
```

ถ้ายังไม่มี `backend/.env` ให้คัดลอกครั้งแรก แล้วแก้รหัส MySQL:

```powershell
Copy-Item backend/.env.example backend/.env
notepad backend/.env
```

ใช้ `DB_NAME=bpes_basic_split` หรือชื่อใหม่เช่น `bpes_basic_split_room01` ไม่ใช้ฐานของฉบับเดิม `PORT=3301` ช่อง `JWT_SECRET` เว้นว่างให้ setup สร้าง

```powershell
npm.cmd run setup
```

เปิด Terminal สองหน้าต่าง **ทั้งคู่ในโฟลเดอร์นี้**:

```powershell
# หน้าต่างที่ 1
npm.cmd run dev:backend
```

```powershell
# หน้าต่างที่ 2
npm.cmd run dev:frontend
```

เปิด **http://127.0.0.1:5175/** ต้องเปิดสอง Terminal ค้างไว้ ปิดด้วย Ctrl+C

| บทบาท | ชื่อผู้ใช้ | รหัสฝึก |
|---|---|---|
| ฝ่ายบุคลากร | admin | Admin1234! |
| ผู้รับ | emp001, emp002 | Emp1234! |
| กรรมการ | eval01, eval02 | Eval1234! |

setup สร้างบัญชีเริ่มต้น ไม่ล้างข้อมูลหรือรีเซ็ตรหัสที่มีอยู่แล้ว ฐานใหม่ยังไม่มีรอบประเมิน ให้ทำตามบท3

**การเข้าใช้ครั้งแรก:** ทุกบทบาทต้องเปลี่ยนรหัสผ่านก่อนใช้เมนูอื่น ใช้รหัสเริ่มต้นในตารางเฉพาะครั้งแรก รหัสใหม่อย่างน้อย8ตัว ต้องต่างจากเดิมและยืนยันตรงกัน ครั้งต่อไปเปลี่ยนได้ที่เมนู “เปลี่ยนรหัสผ่าน”

**อัปเดตจากฉบับก่อนหน้า:** หยุด backend แล้วรัน `npm.cmd run install:all` และ `npm.cmd run setup` จากโฟลเดอร์หลัก จากนั้นเปิดสอง Terminal ตามเดิม setup เพิ่มคอลัมน์รหัสผ่านโดยเก็บข้อมูลเดิม บัญชีในฐานที่ยังไม่เคยมีสถานะนี้จะถูกขอให้เปลี่ยนรหัสครั้งแรก ไม่บังคับซ้ำเมื่อเปลี่ยนแล้ว

**ผู้รับดูผล:** เมนู “ผลการประเมินของฉัน” แสดงรอบของตัวเอง รอบยังไม่เผยแพร่แสดง “รอประกาศผล” รอบเผยแพร่แล้วเปิดคะแนนรวม คะแนนกรรมการ ความเห็นและลายเซ็นได้ กด “ดาวน์โหลด PDF” เพื่อรับไฟล์โดยตรง PDF เก็บภาพรายงานและข้อความไทย จึงไม่รองรับค้นหา/คัดลอกข้อความในไฟล์ ปุ่มพิมพ์เดิมยังมีสำหรับ Chrome/Edge

## ทำทีละระบบ

เปิด `manual/index.html` ด้วยเบราว์เซอร์ สร้างโฟลเดอร์ว่าง `split-practice` เป็นงานฝึกแยก แล้วทำบท1–6 ต่อกัน อย่าคัดลอกเฉลยทั้งหมดก่อนเริ่มเรียน

1. Login / สมัคร / ข้อมูลส่วนตัว
2. จัดการผู้ใช้
3. รอบ / เกณฑ์ / ผู้รับ / กรรมการ
4. ประเมินตนเองและหลักฐาน
5. กรรมการ / ความเห็น / ลายเซ็น
6. รายงาน / เผยแพร่ / พิมพ์ PDF

ไฟล์ `.vue` มีหน้าจอใน `<template>` และคำสั่งใน `<script>` ทุกหน้าส่งข้อมูลผ่าน `frontend/src/api.js` → `/api` → proxy ใน `frontend/vite.config.js` → `backend/server.js` → routes → MySQL รหัสฐานอยู่เฉพาะ `backend/.env`

## ตรวจและ build

```powershell
npm.cmd test
npm.cmd run build
```

ถ้าต้องการดูผล build: หยุด `dev:frontend` ก่อน แล้วรัน `npm.cmd run preview:frontend` ที่พอร์ต5175เดิม โดยยังต้องเปิด backend ค้างไว้ ไม่ใช่เปิด `dist/index.html` โดยตรง

## เมื่อมีปัญหา

- `ECONNREFUSED` / เชื่อมต่อ API ไม่ได้: เปิด backend3301 และเช็ก MySQL
- เข้า3301แล้ว `Cannot GET /`: เป็นพอร์ต API ให้เปิด5175
- `Access denied`: ตรวจ DB_USER/DB_PASSWORD ใน backend/.env แล้วเปิด backend ใหม่
- พอร์ตถูกใช้: หยุด Terminal ที่รันฉบับนี้ซ้ำ ไม่จำเป็นต้องปิดฉบับเก่า
- หลังแก้ package.json: ติดตั้ง dependency ในโฟลเดอร์ที่แก้ และเก็บ lockfile ใหม่ให้คู่กัน
- build เตือน chunk ใหญ่: ฉบับฝึกลงทะเบียน Vuetify ทั้งชุดเพื่อให้เขียนง่าย ไม่ใช่ build ล้มเหลว

คู่มือออฟไลน์เปิดได้โดยไม่รันเซิร์ฟเวอร์ หากแก้เฉลยแล้วต้องปรับกล่องโค้ดในคู่มือด้วย ให้ครูรัน `node teacher/build-manual.mjs` นักเรียนไม่ต้องเรียนไฟล์เครื่องมือนี้

โฟลเดอร์เดิม `reference`, `step-by-step`, `beginner-basic` เก็บไว้ตามเดิม ฉบับนี้ใช้ฐานและพอร์ตแยกกัน
